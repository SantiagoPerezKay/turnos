# Agendador de turnos por WhatsApp

Sistema multi-negocio (consultorios, peluquerías, estudios…) para que los clientes saquen,
consulten y cancelen turnos escribiendo por WhatsApp.

- [`backend/`](backend/README.md) — API (FastAPI + PostgreSQL + WhatsApp Cloud API + Claude)
- [`panel/`](panel/README.md) — panel web (React) para que cada negocio gestione su agenda
